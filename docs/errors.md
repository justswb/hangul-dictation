# 오류 처리

> 스펙: [../SPEC.md](../SPEC.md)

| 상황 | 동작 |
|---|---|
| 네트워크/서버/요청 한도 오류 | 재시도 후 오류 문구, 입력 재활성 |
| 인증 오류 | 제공자·키 입력 화면으로 이동 |
| 거절 응답 | 보드에 "답변할 수 없는 질문이에요" 판서 |
| 스트림 중간 끊김 | 받은 op까지만 그리고 오류 문구 |
| 잘못된 op 줄 | 무시 |
| 중단 | 스트림 취소 + 큐 비움 + 진행 중 획은 그 지점에서 멈춤. 이력에는 실제로 그려진 op만 기록 |
| 지우기 | 보드·페이지 요약·대화 이력 초기화 |
