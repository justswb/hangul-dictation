# 화면 구성

> 스펙: [../SPEC.md](../SPEC.md)

```
┌──────────────────────────────────────────────┐
│                           [⚙ 제공자] [지우기] │
│                                              │
│              화이트보드 캔버스                 │
│            (창 크기에 맞춰 비율 유지)          │
│                                              │
├──────────────────────────────────────────────┤
│ [ 질문을 입력하세요…              ] [전송/중단] │
│  상태: 생각 중… / 쓰는 중…                    │
└──────────────────────────────────────────────┘
```

- 입력: Enter 전송, Shift+Enter 줄바꿈. 응답 중에는 비활성, 버튼은 [중단]으로 바뀜.
- 마커 색: 검정(기본), 파랑, 빨강. AI가 op에서 지정.
- [⚙ 제공자]: 제공자 선택·API 키 입력 화면으로 이동.
- [지우기]: 보드와 대화 맥락 초기화.
