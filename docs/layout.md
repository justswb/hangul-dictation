# 레이아웃 규칙

> 스펙: [../SPEC.md](../SPEC.md) · 크기·간격 수치는 구현 중 정한다

- **흐름**: 좌상단부터 줄 단위로 아래로 배치. 보드 폭을 넘으면 어절 단위 줄바꿈.
- **도식 노드**: `box`는 `place`(`right_of` / `below`)로 상대 배치. 겹치면 오른쪽 → 아래로 밀어냄.
- **화살표**: 두 요소 경계 사이 직선, 라벨은 중점 위.
- **쓰기 전 지우기**: `plan.lines`가 남은 공간보다 크면 첫 획 전에 보드를 지우고 새 페이지에서 시작.
- **넘침**: 예측보다 길어 쓰는 도중 하단을 넘으면 그 시점에 새 페이지. `plan`이 없으면 이 규칙만 적용.
- **보드 크기**: 고정 논리 좌표계를 쓰고 창 크기에 맞춰 비율 유지 스케일.
